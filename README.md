# Neon Harbor

ブラウザで動くリアルタイム3Dの湾岸都市マップ（Three.js r170 / WebGL2）。`index.html` を開くだけで動作します（three.js は jsDelivr から読み込み）。

## 操作
- 「歩く」モード: 地上を歩行（重力・段差・建物/街路樹との衝突あり）。Shift で走る、Space でジャンプ
- 「飛ぶ」モード: 自由飛行。Space・E で上昇、C・Q で下降、Shift で加速
- WASD / 矢印: 移動　マウス: 視点（クリックでポインタロック、ドラッグでも可）
- F: 歩く⇄飛ぶ　T: 時間帯　R: 雨　H: UI表示切替
- スマホ: 左側をドラッグした位置にジョイスティックが出る（倒し切ると走る）、右側ドラッグで視点、JUMP / ▲▼ ボタン

## 描画の主な要素
- PBR（MeshStandard/Physical）＋ 空シェーダーから生成した PMREM 環境マップ
- 平面リフレクション＋水たまりノイズ・雨の波紋による濡れた路面と湾の反射
- 建物は多角形押し出しで生成（角丸・面取り・円筒・L字、基壇＋セットバック＋頂部意匠）
- 街区種別: 超高層の都心、オフィス街、雑居ビル・マンション・レンガ造が並ぶ低層街（電柱と電線付き）
- 手続き的ファサード（ガラスカーテンウォール、横連窓、タイル、レンガ目地、雨だれ汚れ、バルコニー、店舗・シャッター）
- 信号機（横型）に従って停止・発進する交通、ブレーキランプ、自販機、日除け、屋上の受水槽・設備
- HDR ブルーム、ACES トーンマッピング、MSAA、ビネット／色収差／フィルムグレイン
- 太陽/月のソフトシャドウ（視点追従）、近傍街灯8灯の動的ライト
- 車の交通、ネオン看板、LEDビジョン、吊り橋のイルミネーション、雨パーティクル
